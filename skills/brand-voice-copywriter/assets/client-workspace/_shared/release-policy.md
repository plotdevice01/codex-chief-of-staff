# Release policy

Package adoption does not approve every asset. An asset becomes `Public ready` only when its exact version has current sources, rights, channel checks, required owner decisions, and the release owner's decision.

Use `Hold` when a hard gate fails. Use `Internal rehearsal` for structurally complete material that still contains placeholders or fictional facts.

Run AI Sloppy Copy on the complete asset before release. Its language check does not replace fact review or owner approval.
