# Anchor

## Inputs

Approved copy, client brand files, two to four assigned references, and cover prompt records.

## Process

Generate three distinct cover compositions. Inspect exact text and hierarchy. Check mobile legibility plus brand fit. Confirm rights. Then test curiosity. Select and refine one visual anchor.

## Outputs

Approved cover candidate plus frozen anchor rules in `visual-brief.md`. Save the prompt records too.

## Human check

Approve one cover and its anchor rules before the remaining slides are generated.
