# Release

## Inputs

Final ordered files, copy, prompt history, sources, rights decisions, platform verification, caption, alt text, and prior approvals.

## Process

Run the manifest validator. Check exact copy, file count, dimensions, order, visual consistency, accessibility, claims, disclosures, rights, and live route constraints. Export the delivery format.

## Outputs

Completed `qa.md`, validated `run.json`, final images or PDF, and a release record.

## Human check

Record release approval for the exact package. Publication requires separate explicit authorization.
