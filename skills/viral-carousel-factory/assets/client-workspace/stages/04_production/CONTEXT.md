# Production

## Inputs

Approved anchor, exact slide copy, brand assets, assigned references, and per-slide prompts.

## Process

Generate one slide at a time. Inspect each result before continuing. Repair text errors and crop risks. Fix contrast failures plus style drift. Remove repeated visuals or false details. Stop unsafe brand use.

## Outputs

Separate ordered slide files plus complete prompt records. Save visual QA notes too.

## Human check

Review the complete ordered carousel at thumbnail and full size before release packaging.
