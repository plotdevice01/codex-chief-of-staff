# Companion integrations

Chief of Staff is installable by itself. The plugin contains the retained
persona, response modes, account gates, project routing, and the core Ponytail
efficiency ladder.

The reference installation also uses:

| Integration | Minimum | Purpose |
|---|---:|---|
| Ponytail | 4.8.4 | Persistent implementation discipline, modes, hooks and review skills |
| AI Sloppy Copy | 2.1.0 | Authored-copy rules and deterministic copy checking |

These packages remain separate so each can update independently. Chief of
Staff validation warns when either companion is missing and
`--strict-dependencies` turns those warnings into failures.

No other repository, runtime service, MCP server or database is required. No paid account is
required.
